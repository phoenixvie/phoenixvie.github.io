Anmelden

Beim ersten Besuch bitte ein eigenes Passwort festlegen. Falls eine E-Mail-Bestätigung aktiviert ist, bestätige zuerst die Nachricht in deinem Postfach.

Neue Speisen und Struktur zuerst auf Deutsch anlegen. English bearbeitet nur Übersetzungen; Preise und Menüzuordnung bleiben unverändert.

Automatische Menüprüfung

Geplante Prüfungen durch GitHub Actions, jeweils Wiener Zeit:

  • Montag: stündlich von 06:15 bis 18:15 Uhr
  • Dienstag bis Freitag: stündlich von 08:15 bis 12:15 Uhr
  • Samstag: stündlich von 08:15 bis 18:15 Uhr
  • Sonntag: keine automatische Prüfung

Zusätzliche Prüfungen können bei einer manuellen Auslösung des GitHub-Workflows erfolgen.

Menüs manuell bearbeiten
